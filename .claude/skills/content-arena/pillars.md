# Akira's brand pillars

Main message: running a business with a partner is more fun, less work, faster scale.

1. Solo grind → burnout: partner/hire so you only do highest-leverage work
2. Non-materialistic: family first, no flexing
3. Back-end matters as much as front-end: fulfillment bottlenecks kill scale
4. If you're not tracking, you're slacking: track leads, objections, which video brought each buyer
5. D1 Offer: great fulfillment > everything; premium onboarding
6. Enemy: TOFU/MOFU/BOFU is dead; content is an ecosystem of touch-points
7. Content: buyer's journey, 7/11/4 touch-points, long-form nurtures, setters feed objections to editors
8. Sale process: rapport → qualify → pain dig → pitch with a real case study; ban-proof DMs
9. AI automation: automate the bottleneck, not the business; AI script director helps, doesn't write

Audience: B2B coaches/founders ($20K-100K/month) who want content that converts, not just views.
